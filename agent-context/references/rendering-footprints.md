# Rendering Footprints

Render plans must provide a compact teaching view:

- breadboard: base workspace.
- arduino: controller board.
- oled: four-pin display module.
- led: small two-pin load.
- resistor: inline passive between signal source and LED.
- button: tactile input.
- buzzer: two-pin sound output.
- servo: three-pin actuator module.

When a footprint is unknown, do not render a final part. Return unsupported context instead.
