# Legacy Context Layer v1 Snapshot

This is a preservation copy of the root context layer as of 2026-06-01.

It is not the active runtime context root. Current tools and agents still read from `agent-context/` and the bundle-first layer in `agent-context/v2/`.

Use this snapshot for comparison, rollback analysis, or migration review only. Do not add new supported hardware here; add it to the active context layer and its source/support bundle records first.
