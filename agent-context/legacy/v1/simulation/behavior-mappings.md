# Behavior Mappings

- OLED text: display_static_text plus current_flow_animation for the module load.
- LED blink: blink_timer plus LED current path.
- Button controls LED: digital_on_off plus button state control.
- Buzzer alarm: analog_threshold or digital_on_off plus buzzer_pulse.
- Servo sweep: servo_angle plus current warning.
- Fault cases: fault_visualization only, no normal current animation.
