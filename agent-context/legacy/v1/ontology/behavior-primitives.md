# Behavior Primitives

- on_off: a digital output changes between off and on.
- threshold: an output changes when a sensor crosses a value.
- toggle: a button alternates state.
- timer: a state changes after time.
- sequence: several outputs change in order.
- analog_mapping: a sensor value maps to brightness, angle, tone, or display text.
- display_value: a display shows a number or message.
- alert: buzzer, LED, or display warns the student.
