# Clarification Policy

Ask one short question only when missing information changes topology, safety, or simulation support.

Choose safe defaults when the choice is educationally harmless: Arduino Uno, breadboard, USB 5V, beginner-safe module, and conservative current limits.

Do not ask category-selection questions when intent can be inferred. Ask about the learner's desired sensing target, output feedback, or safety-critical power source.

After three unanswered clarifications, propose the simplest safe project and mark assumptions explicitly.
