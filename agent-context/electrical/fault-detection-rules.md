# Fault Detection Rules

Required deterministic fault codes:

- DIRECT_POWER_SHORT
- LED_WITHOUT_RESISTOR
- LED_REVERSED_POLARITY
- MISSING_COMMON_GROUND
- FLOATING_DIGITAL_INPUT
- ANALOG_SENSOR_ON_DIGITAL_ONLY_PIN
- MOTOR_DIRECT_TO_GPIO
- SERVO_CURRENT_WARNING
- CONFLICTING_VOLTAGE_DOMAIN
- I2C_LINES_SWAPPED
- MISSING_PULLUP_WHEN_REQUIRED
- UNSUPPORTED_MAINS_VOLTAGE

Every issue must include severity, student explanation, and repair hint.
