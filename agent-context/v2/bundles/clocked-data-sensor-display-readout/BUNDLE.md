# Clocked Data Sensor Display Readout

Use this bundle when the student explicitly asks for an HX711 load-cell amplifier value shown on an I2C OLED or supported I2C character LCD.

Supported: Arduino Uno, breadboard, HX711 VCC/GND/DT/SCK, I2C display wiring, qualitative load/weight trend readout, sensor supply current, data/clock activity, and display bus activity.

Required wiring: HX711 VCC to safe 5V, GND to common GND, DT to Arduino D2, SCK to a digital output such as D3, display SDA to A4/SDA, and display SCL to A5/SCL.

Simulation: qualitative classroom load-cell trend only. Do not claim legal-for-trade weight, calibration, certification, or exact mass measurement.
