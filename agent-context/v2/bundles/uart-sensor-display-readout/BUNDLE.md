# UART Sensor Display Readout

Use this bundle when the student explicitly asks for a NEO-6M GPS module classroom readout on an I2C OLED or supported I2C character LCD.

Supported: Arduino Uno, breadboard, GPS VCC/GND/TX/RX, I2C display wiring, qualitative NMEA/location-state demo, UART signal activity, and display bus activity.

Required wiring: GPS VCC to safe low-voltage power, GND to common GND, GPS TX to Arduino D0/RX, display SDA to A4/SDA, and display SCL to A5/SCL. GPS RX is optional for the supported readout.

Simulation: educational NMEA/GPS state only. Do not claim tracking, navigation guidance, autopilot, collision avoidance, security, or safety use.
