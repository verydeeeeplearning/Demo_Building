# SPI Sensor Display Readout

Use this bundle when the student explicitly asks for an RC522 RFID module demo readout on an I2C OLED or supported I2C character LCD.

Supported: Arduino Uno, breadboard, RC522 3V3/GND/SCK/MOSI/MISO/CS, I2C display wiring, qualitative tag-present/tag-id demo state, SPI bus activity, and display bus activity.

Required wiring: RC522 3V3 to Arduino 3V3, GND to common GND, SCK to D13, MOSI to D11, MISO to D12, CS to D10, display SDA to A4/SDA, and display SCL to A5/SCL.

Simulation: educational RFID demo only. Do not claim access control, payment, authentication, door locks, alarms, or real security.
