# UART Communication Module Readout

Use this bundle when the student explicitly asks for ESP-01 WiFi, HC-05 Bluetooth, or SIM800L GSM module status/AT-command state on an I2C OLED or supported I2C character LCD.

Supported: Arduino Uno, breadboard, module VCC/GND/TX/RX, I2C display wiring, local command/status state, UART signal activity, and display bus activity.

Required wiring: module VCC to safe module power, GND to common GND, module TX to Arduino D0/RX, module RX to Arduino D1/TX, display SDA to A4/SDA, and display SCL to A5/SCL.

Simulation: local command-state only. Do not claim real internet, cloud backend, phone pairing, SMS/call delivery, tracking, security, RF range, or cellular service.
