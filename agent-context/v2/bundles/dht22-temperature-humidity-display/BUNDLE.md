# DHT22 Temperature/Humidity Display

Use this bundle when the student explicitly asks for a DHT22 or AM2302 temperature/humidity sensor readout on an I2C OLED or supported I2C character LCD.

Supported: Arduino Uno, breadboard, DHT22 VCC/GND/DAT, I2C display VCC/GND/SDA/SCL, qualitative temperature/humidity state, single-wire data activity, and display bus activity.

Required wiring: DHT22 VCC to safe 5V, GND to common GND, DAT to Arduino D2, display SDA to A4/SDA, display SCL to A5/SCL, and display power/ground to the shared low-voltage rails.

Simulation: qualitative classroom temperature/humidity readout only. Do not claim calibrated weather-station accuracy, fast sampling, medical use, navigation use, or safety monitoring.
