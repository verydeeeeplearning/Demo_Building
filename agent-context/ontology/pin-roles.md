# Pin Roles

- power input: receives supply.
- power output: provides a limited supply.
- ground: common return/reference.
- digital input: reads HIGH/LOW.
- digital output: drives a small logic load.
- analog input: reads variable voltage.
- PWM output: emits pulse-width modulation.
- bus data: carries protocol data.
- bus clock: carries bus timing.
- actuator drive: controls driver modules, not high-current loads directly.
