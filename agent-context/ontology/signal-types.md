# Signal Types

- power: supplies energy, such as Arduino 5V.
- ground: return path and voltage reference.
- digital: HIGH/LOW logic signal.
- analog: variable voltage read by analog input.
- pwm: timed pulse output used for brightness or servo control.
- i2c-data: SDA bus data line.
- i2c-clock: SCL bus clock line.
- spi: clock and data bus signals.
- uart: TX/RX serial signals.
- control: non-power actuator command signal.
